# Dek — instalador para DEKSI Web

Aquí se publican las versiones del instalador de **Dek**, el asistente que conecta DEKSI Web con tu PC.

- Descarga siempre la última versión en la sección **Releases**.
- El instalador se construye para una sola web (https://deksiweb.vercel.app): solo se empareja con ella.
- Las versiones aún no están firmadas: Windows puede mostrar el aviso de SmartScreen.
